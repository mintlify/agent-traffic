agent-traffic ships a skill that teaches your coding agent how classification works and how to use the package and dataset. Install it, then ask your agent for whatever you need.

<Prompt description="Install the agent-traffic skill" icon="robot">
Install the agent-traffic skill with `npx skills add mintlify/agent-traffic`.
</Prompt>

The skill installs through the [skills CLI](https://skills.sh), which supports Claude Code, Cursor, Codex, OpenCode and other agents.

## Other ways to install

<Tabs>
  <Tab title="Point your agent at it">
    If you'd rather not install anything, give your agent the skill's URL:

    <Prompt description="Use the skill without installing it" icon="link">
    Read https://github.com/mintlify/agent-traffic/blob/main/skills/agent-traffic/SKILL.md to learn how to use agent-traffic.
    </Prompt>
  </Tab>
  <Tab title="npm package">
    The skill ships inside the package at `node_modules/agent-traffic/skills/agent-traffic/SKILL.md`. Copy it into `.claude/skills/` or wherever your agent loads skills from.
  </Tab>
</Tabs>

## What the skill covers

- **How classification works:** the categories, the order of checks, and when an identity counts as verified.
- **How to use it in different places:** the package in JavaScript request handlers, porting the rules to other languages, and querying stored logs with a lookup table or generated SQL, with pattern translations per database.
- **How to check the result:** running the dataset's real example user agents through whatever your agent builds.
- **How to report the numbers:** keeping agents and crawlers separate, and what to do when replacing an existing metric.
