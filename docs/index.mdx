`agent-traffic` classifies HTTP requests. It's a curated, tested dataset of the user agents, headers and official verification sources of real agents and crawlers, plus one small function that applies it.

## What it does

```js
import { classify } from '@mintlify/agent-traffic'

classify({ userAgent: 'Claude-User (claude-code/2.1.308; +https://support.anthropic.com/)' })
// { category: 'agent', kind: 'coding', name: 'Claude Code', operator: 'Anthropic', version: '2.1.308', ... }
```

## Why it exists

Most bot lists match a user agent substring and return a label. That breaks down for AI traffic in three ways:

- **Claims aren't verified.** Anyone can send `GPTBot` in a user agent. `agent-traffic` checks crawlers against their operators' published IP ranges and flags impersonators.
- **Different kinds of AI traffic get lumped together.** A coding agent reading your docs for a developer, an AI company crawling for training data, and a script mirroring your `llms.txt` are very different things. Each gets its own category.
- **Agents hide behind browser user agents.** Many AI tools send a stock Chrome user agent but still ask for markdown. The classifier looks at headers, not only the user agent.

Every result explains itself with a list of reasons, so you can see why a request landed where it did.
